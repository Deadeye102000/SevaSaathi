# Leave Application Process — Manav Sampada eHRMS

1. Employee submits a leave application specifying type, start date, end date, and reason.
2. System checks current leave balance for the requested leave type.
3. If balance is sufficient, application status is set to "Pending" and routed to the employee's reporting officer.
4. If balance is insufficient, the employee is notified immediately and may choose a different leave type or reduce the duration.
5. Reporting officer reviews the application in their eHRMS dashboard and approves or rejects it, with an optional remark.
6. On approval, the employee's leave balance is debited and a confirmation is generated with a unique application ID.
7. On rejection, the balance remains unchanged and the employee is notified with the officer's remark.
8. Employees can check the status of any application at any time using the application ID or by asking for their latest applications.
